# Long Margin Correction Call 2026-07-17

Thirty-minute call with [[priyanka-desai|Priyanka Desai]] and [[callum-pryce|Callum Pryce]] two days after [[long-margin-interview-2026-07-15|issue 31]] came out.

## Decisions

- Ask for an online correction, not a print one (the next print issue is three months away and would only repeat the title). Priyanka to send the request that afternoon; Callum copied.
- The request: remove "shipwreck novel", attribute any description of the book to the interviewer, and mark the title as provisional. Do not ask for the title to be removed; that would draw attention to it.
- From now on, nothing public about book two beyond "a 1920s coastal town" until the catalogue announcement. Written down the same evening as [[what-i-say-in-public-about-book-two]].
